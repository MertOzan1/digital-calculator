
# 🧮 Digital Calculator

A responsive digital calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Decimal number support
- Clear and backspace buttons
- Power on/off functionality
- Responsive user interface
- Modular JavaScript using ES modules

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES modules)

## What I Learned

- Organizing JavaScript code into modules
- Importing and exporting functions
- Handling user interactions with event listeners
- Working with conditional statements and error handling
- Designing a responsive interface with CSS
